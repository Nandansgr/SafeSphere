# SafeSphere – Safety & Alert System

SafeSphere is a web-based **Safety & Alert Management System** developed as a DBMS project. It demonstrates **CRUD (Create, Read, Update, Delete) operations** for managing users, emergency contacts, SOS alerts, and incident reports.

## Features

* User registration and profile management
* Emergency contact management
* SOS alert creation and tracking
* Incident reporting and management
* Complete database CRUD operations
* Responsive and user-friendly interface

## Technologies

* Frontend: HTML, CSS, JavaScript
* Database: SQL
* Git & GitHub

## Objective

To demonstrate practical **DBMS concepts, database relationships, and CRUD operations** through a real-world safety and emergency alert application.

**Project Type:** DBMS / Web Application
**Domain:** Safety & Emergency Management
